= Seegson FastDelivery: Operations Runbook
:description: Day-to-day operations runbook for a multi-vendor telecom infrastructure, written as docs-as-code.

image::fastdelivery-ducks.jpg[FastDelivery,240,role=right]

This is the operations runbook of the FastDelivery platform: the procedures a network and systems operations team used every day on a multi-vendor telecom infrastructure, from firewall changes and certificate renewals to patching, monitoring and the final decommissioning.

It is written in AsciiDoc and kept in Git. The same source builds this site with Antora and a PDF with Asciidoctor PDF, both in GitHub Actions on every change.

* *Download the PDF:* {pdf-url}[fastdelivery-runbook.pdf]
* *Source and build pipeline:* {repo-url}[github.com/gsaronni/docs-as-code-showcase]

[NOTE]
====
The platform has been decommissioned, and every identifier has been fictionalised: organisations, people, domains, hostnames and addresses borrow from the _Alien_ universe (Seegson is the operator, Weyland-Yutani runs operations). Vendors and products are real.
====
